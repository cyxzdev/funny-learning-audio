# Funny Learning audio
Recordings for the Funny Learning alphabet posters (non-commercial, home/classroom use).

- `<Letter>/<word>.m4a`: phonics sound, then the word.
- Letter (phonics) sounds: audio by Philip Neal Whitman for the Intercultural English Language Programs' Spoken English Program, The Ohio State University, 2023. Released under a Creative Commons Attribution-NonCommercial licence (CC BY-NC). Isolated sounds were cut from the original recordings and joined with spoken words.
- Spoken words: Microsoft Edge neural voice (Ava).
