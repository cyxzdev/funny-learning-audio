# Funny Learning audio
Recordings for the Funny Learning alphabet posters (home/classroom use, not sold).

`<Letter>/<word>.m4a`: the word's first (phonics) sound twice, then the word. Both are cut from the same
real human recording of the word, so the voice always matches. Most recordings are by Dvortygirl.

Sources (Wikimedia Commons, CC BY-SA; trimmed, joined and re-encoded): Wiktionary "En-us-<word>.ogg"
pronunciations and Lingua Libre "LL-Q1860 (eng)" recordings. The speaker for every clip is listed in
credits.json. Words with no free recording use the Microsoft Edge neural voice Ava.
